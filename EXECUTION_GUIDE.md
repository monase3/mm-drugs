# دليل تشغيل نظام MM Drugs محلياً

> **Arabic | عربي** — الخطوات أدناه لتشغيل النظام كاملاً على شبكتك المحلية.

---

## 1. تشغيل خادم Next.js (Backend)

افتح **طرفية (Terminal) أولى** في مجلد `mm-drugs`:

```bash
# 1. تثبيت الاعتماديات (مرة واحدة فقط)
npm install

# 2. تشغيل الخادم بحيث يكون متاحاً على всей الشبكة المحلية
npx next dev -H 0.0.0.0 -p 3000
```

الخادم سيعمل الآن على `http://0.0.0.0:3000` — متاح لجميع الأجهزة على نفس شبكة Wi-Fi.

### الحصول على عنوان IP المحلي

في **طرفية ثانية**، نفّذ:

```bash
# Windows PowerShell
ipconfig | Select-String -Pattern "IPv4"
```

ابحث عن عنوان يبدأ بـ `192.168.` أو `10.` — ستحتاجه لاحقاً لربط تطبيق Flutter و POS Bridge. مثال: `192.168.1.105`.

## 2. تشغيل POS Bridge (حقن بيانات المخزون)

> **ملاحظة مهمة:** يجب أن يكون لديك صيدلية مسجلة في قاعدة البيانات بمفتاح API صحيح.  
> يمكنك إضافتها يدوياً عبر SQL أو من خلال واجهة تسجيل الصيدليات.

افتح **طرفية ثالثة** في مجلد `mm-drugs\pos_bridge`:

### 2.1. إعداد المتغيرات

انسخ ملف البيئة وعدّل المفتاح:

```bash
# Windows
copy .env.example .env
```

عدّل ملف `.env` — ضع مفتاح API الخاص بصيدليتك وعنوان الخادم:

```env
PHARMACY_API_KEY=mk_xxxxxxxxxxxxxxxxxxxx
SERVER_URL=http://192.168.1.105:3000
```

### 2.2. تثبيت الاعتماديات والتشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل المزامنة
npm run sync
```

النتيجة المتوقعة:

```

## 3. تشغيل تطبيق Flutter على جهاز Android فعلي

### 3.1. تعديل عنوان الخادم في التطبيق

افتح الملف `mobile_app\lib\services\api_service.dart` وغيّر الرابط الافتراضي من `http://localhost:3000` إلى عنوان IP المحلي لجهاز الكمبيوتر:

```dart
// قبل التعديل
baseUrl: baseUrl ?? 'http://localhost:3000/api',

// بعد التعديل (استخدم عنوان IP الخاص بك)
baseUrl: baseUrl ?? 'http://192.168.1.105:3000/api',
```

> **هام:** تأكد من تعطيل SSL وعدم استخدام `https` لأن الخادم المحلي يعمل على HTTP عادي.

### 3.2. السماح باتصالات HTTP (لنظام Android)

في **Android**، يجب السماح بـ `cleartext traffic` للتطوير المحلي.  
افتح `mobile_app\android\app\src\main\AndroidManifest.xml` وأضف:

```xml
<application
    android:usesCleartextTraffic="true"
    ...>
```

### 3.3. تشغيل التطبيق

افتح **طرفية رابعة** في مجلد `mobile_app`:

```bash
# تأكد من توصيل جهاز Android عبر USB مع تفعيل USB Debugging

# التحقق من الأجهزة المتصلة
flutter devices

# تشغيل التطبيق
flutter run
```

> إذا طلب التطبيق مفتاح Google Maps، أضف مفتاح API في:
> - `android/app/src/main/AndroidManifest.xml` ← داخل `<application>` أضف:
>   ```xml
>   <meta-data
>       android:name="com.google.android.geo.API_KEY"
>       android:value="YOUR_API_KEY_HERE"/>
>   ```

| الخطوة | الأمر | المجلد |
|---|---|---|
| تشغيل الخادم | `npx next dev -H 0.0.0.0 -p 3000` | `mm-drugs/` |

| مزامنة POS | `npm run sync` | `mm-drugs/pos_bridge/` |
